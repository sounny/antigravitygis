# GIS Antigravity Agent Rules

These rules govern the behavior of the Antigravity Agent when operating within GIS platforms (ArcGIS Pro, QGIS, or standalone ArcPy/PyQGIS scripts).

## 1. Safety & Data Integrity
- **Non-Destructive Execution**: Always inspect feature layers, geometry types, spatial references, and field definitions before modifying spatial data.
- **Geodatabase & Shapefile Backups**: When running geoprocessing operations that mutate input feature classes in-place (e.g. `CalculateField`), verify or recommend creating a copy/backup.

## 2. Spatial Context Awareness
- Always report projections, Coordinate Reference Systems (CRS/SRID), units, and record counts when listing GIS datasets.
- Warn the user if mixing datasets with incompatible coordinate systems without on-the-fly transformation.

## 3. Platform Agnosticism
- Core agent logic (`agent_core.py`) must remain decoupled from specific UI bindings (ArcGIS Pro `.pyt` or QGIS Python plugin) to enable cross-platform reuse.

## 4. Data Privacy & Sensitive Data Handling
- **Sensitive Data Warning**: Warn users whenever handling datasets containing PII (personally identifiable information), proprietary business data, or classified spatial features.
- **Human Verification**: Remind users that spatial analysis and geoprocessing decisions generated by AI models must be reviewed and verified by a qualified GIS professional before deployment into critical production environments.
