# AntigravityGIS

Designed by Sounny to bridge modern agentic AI models with desktop GIS software. AntigravityGIS empowers spatial analysts, GIS engineers, and cartographers with natural language spatial copiloting inside Esri ArcGIS Pro and QGIS.

**Official Website:** [https://antigravitygis.sounny.com/](https://antigravitygis.sounny.com/)

## Installation

You can download the installers directly from the `dist/` folder in this repository, or by visiting our website.

- **ArcGIS Pro**: `dist/Install-AntigravityGIS.exe`
- **QGIS**: `dist/Install-AntigravityGIS-QGIS.exe`

## Features

- **Natural Language Spatial Copiloting**: Talk to your GIS. Give it instructions in plain English and let the AI do the heavy lifting.
- **Cross-Platform Support**: Works seamlessly inside Esri ArcGIS Pro and QGIS.
- **Powered by Google Antigravity**: Uses cutting edge AI agent technologies to read and manipulate your map layers.

## Note on Executables
If your browser or Windows SmartScreen flags the `.exe` files, this is a common false positive for unsigned PyInstaller executables. You can safely "Run Anyway" or download the `.zip` packages from our website instead.
